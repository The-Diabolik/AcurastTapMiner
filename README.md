# Acurast Tap Miner — prototype v2

## Contenu
- `index.html`: jeu responsive en français.
- Minage manuel, revenus automatiques, équipements, bonus quotidien.
- Sauvegarde locale navigateur.
- Aperçu de classement hebdomadaire : les autres joueurs sont des données de démonstration, pas un classement connecté.

## Tester
Décompresser le ZIP puis ouvrir `index.html` dans un navigateur récent.

## Important
- Les cristaux sont des points virtuels sans valeur monétaire.
- Aucun paiement, token, wallet, récompense réelle, compte utilisateur ou classement partagé n'est implémenté.
- Le classement multi-joueurs nécessite un backend et une validation serveur anti-triche.
- Toute récompense crypto devra être financée et soumise à une analyse technique, juridique et fiscale.
- Prototype indépendant, non affilié officiellement à Acurast.

## Étape technique suivante
Construire une API backend (par exemple avec Node.js) pour gérer les comptes, scores hebdomadaires, validation des actions, règles de classement et un fonds de récompenses. Acurast peut exécuter des applications et API backend, mais l'hébergement du frontend statique et le backend sont des composants distincts.
Documentation officielle : https://docs.acurast.com/developers/
